# catalog3d - Каталог товаров мастерской по 3d печати Pogodin_3D
Доступ к каталогу осуществляется по ссылке - https://aleksey998.github.io/catalog3d/

При помощи данного каталога Вы можете:
1. Посмотреть все доступные для заказа товары в моей мастерской с актуальной ценой;
2. Оформить заказ конкретного товара при помощи Telegram или Instagram;
3. Узнать про способы и сроки доставки товаров;
4. Следить за пополнением товаров в моей мастерской.

Добро пожаловать в мой мир 3D печати!
